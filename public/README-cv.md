# CV Download

The site serves the CV from `public/curtis-irwin-cv.pdf`, which is linked by the
**Download CV** buttons in the nav bar and hero section on the home page.

## To update your CV

Replace `public/curtis-irwin-cv.pdf` with your real CV file. Keep the exact same
filename (`curtis-irwin-cv.pdf`) so the download links keep working — no code
changes needed.

If you want a different filename, update the two `href="/curtis-irwin-cv.pdf"`
links in `src/app/page.tsx` to match.

> The PDF currently in this folder is a placeholder.
